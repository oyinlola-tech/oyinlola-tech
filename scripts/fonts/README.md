# Fonts

Latin subsets of the three variable fonts the portfolio uses. `build_assets.py`
reads them to turn text into outlines; they are never served to a browser.

| File | Family | Licence |
| --- | --- | --- |
| `InterTight-latin.woff2` | [Inter Tight](https://fonts.google.com/specimen/Inter+Tight) | SIL Open Font License 1.1 |
| `Inter-latin.woff2` | [Inter](https://rsms.me/inter/) | SIL Open Font License 1.1 |
| `JetBrainsMono-latin.woff2` | [JetBrains Mono](https://www.jetbrains.com/lp/mono/) | SIL Open Font License 1.1 |

The licence text is at <https://openfontlicense.org>. It permits bundling and
converting glyphs to outlines.
