# Icons

Brand marks from [Simple Icons](https://simpleicons.org) (CC0 1.0), pinned at
v13. `build_assets.py` embeds their paths into `assets/stack.svg`, lifting
colours that would vanish on a dark surface. The Zudojs mark is not here: it
is drawn in code from the geometry at <https://zudojs.oyinlola.site>.

To add one: download `https://cdn.jsdelivr.net/npm/simple-icons@v13/icons/<slug>.svg`
into this folder, add a row to `STACK` in `build_assets.py`, and rebuild.
